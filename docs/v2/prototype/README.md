# Prototype navigable V2

Maquette HTML autonome (vanilla JS, aucune dépendance) qui sert de référence visuelle et fonctionnelle pour la V2.
Version publiée : https://claude.ai/artifact/JP6w3gr8vX4UGCQrZDkj8D

- `index.html` : toute l'app (écrans, navigation, bascule mobile / ordinateur)
- `img/` : images V1 compressées en WebP utilisées par la maquette

Pour l'ouvrir : télécharger le dossier et ouvrir `index.html` dans un navigateur.
Ce dossier n'est pas servi par le site (il est hors de `public/`).
