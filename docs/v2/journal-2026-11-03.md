```
sudo cp ~/Toutou/deploy/toutou-opff-import.service ~/Toutou/deploy/toutou-opff-import.timer /etc/systemd/system/ && sudo systemctl daemon-reload && sudo systemctl enable --now toutou-opff-import.timer && sudo systemctl start toutou-opff-import.service && echo IMPORTED
```

### (archive) Mettre en ligne le scanner (friandises, copie Open Pet Food Facts) et la fiche de garde

Tout est réuni sur la branche `release/scanner-garde`, testée sur la préversion (pages en 200, aucune erreur). Il faut d'abord créer 3 tables dans la base de production. Colle cette ligne dans Termius :

```
cd ~/Toutou && git fetch -q origin release/scanner-garde && D=$(mktemp -d) && git archive origin/release/scanner-garde db drizzle.config.ts | tar -x -C $D && ln -s /srv/toutou/current/node_modules $D/node_modules && chmod -R a+rX $D && sudo -u toutou env DATABASE_URL='postgresql:///toutou?host=/var/run/postgresql' bash -c "cd $D && npx drizzle-kit migrate" && echo MIGRATED
```

Quand tu vois `MIGRATED`, écris « done » : je mets en ligne, je vérifie, puis je te donne la ligne qui installe la copie du dimanche et lance le premier import.
